# ilyaaltman.com

Placeholder site for ilyaaltman.com, kept until Ilya turns 18. It shows Ilya's age as a live clock over a sky that follows the real sun and weather in Haifa.

Everything is in `index.html` with no build step. Serve it with `python3 -m http.server 8000`, and try other skies with `?time=dawn|noon|sunset|night` and `?weather=clear|clouds|rain|storm|fog`.

The sister site, leonidaltman/yakov-altman (yakovaltman.com), uses the same file with a different name and birth date. Pushing to `main` deploys.
